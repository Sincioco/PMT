## Audit scope and authority

This is the required audit-before-implementation record for Phase 7. It applies the current-main amendment to the original Phase 7 instructions and records current behavior before any production-code change.

Sin has extensively tested Diagram 2 and considers its current observable behavior authoritative. Diagram 2 behavior is preserved unless this audit reproduces a specific Phase 7 defect. Diagram 1 is not a general UI oracle. Its Version 1.27 production baseline is used only as the compatibility oracle for Diagram 1 PMT Diagram export and the Diagram 1 to Diagram 2 transition.

The worktree was clean at audit start. The six commits after the amendment's observed SHA are `ef5de3e`, `7235cd7`, `712f3ef`, `a64fe95`, `59dfcb7`, and `cc3b6ff`. They added Diagram 2 document security and conflict behavior, the native public viewer, mapping and linked-viewer polish, responsive relationship tracing, and screen capture. They did not change the shared PMT Diagram codec or the Diagram 1 PMT export implementation beyond cache-key updates.

The current Diagram 1 `exportPmtDiagram`, portable-annotation builder, export normalizer, and shared PMT v1 create/parse codec are text-identical to the Version 1.27 oracle after line-ending normalization. The frozen Version 1.27 schema SVG also has the same Git blob at the oracle and current HEAD. Diagram 1 export is therefore protected and will not be changed in Phase 7.
