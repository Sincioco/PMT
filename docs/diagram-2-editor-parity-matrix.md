# Diagram 2 Editor Parity Matrix

This matrix began as the Phase 1 authoritative inventory for bringing Diagram 2 editor behavior to Diagram 1 parity. It now records implementation and automated verification through Phase 7 while retaining the historical phase-by-phase closure notes that explain when each capability was completed. The current Phase 7 change set is ready for Sin's manual testing but is not manually accepted yet.

Phase 1 did not implement editor features. Phases 2-6 completed the editor foundation and feature surface, and Phase 7 supplied the implementation and automated evidence for the document, save, import/export, round-trip, dialog, keyboard, context-menu, accessibility, and lifecycle requirements. No applicable current row retains a forbidden incomplete status; `Not Started` and `UI Only` appear only in the legend or an explicitly historical Phase 2 closure entry. Final Phase 7 acceptance remains pending Sin's manual test of this change set.

The post-Phase 1 visual editor parity addendum is incorporated here with the approved Phase 2 correction: Diagram 2 must visually present the familiar Diagram 1 editor by default, while keeping Objects in the right inspector tab/pane as shown in the final Phase 2 screenshots. Toolbar grouping/order, center canvas, right inspector tab names and order, dialogs, context menus, selection affordances, shortcuts, and save/import/export workflows should remain familiar unless Sin explicitly approves a visible difference. This mandate does not permit copying Diagram 1's slow rendering lifecycle; every Diagram 2 behavior still routes through Diagram 2 commands, dirty categories, keyed SVG patches, selective routing, virtualization, and compatibility-safe persistence.
